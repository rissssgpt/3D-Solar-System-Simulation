# 3D Solar System Simulation with Three.js

This project is a 3D simulation of our solar system built with Three.js. It includes all 8 planets orbiting the Sun with adjustable speed controls.

## Features

- Realistic 3D rendering of the solar system
- Adjustable orbital speeds for each planet
- Pause/Resume functionality
- Responsive design that works on mobile devices
- Starry background
- Interactive camera controls (zoom, pan, rotate)

## How to Run

1. Clone or download this repository
2. Open the `index.html` file in a modern web browser
   - No server needed - it will run directly from the file system
3. Interact with the simulation:
   - Use the sliders to adjust planet speeds
   - Click "Pause" to stop the animation
   - Use mouse to rotate/zoom the view

## Requirements

- Modern web browser (Chrome, Firefox, Edge, Safari)
- Internet connection (to load Three.js from CDN)

## Implementation Details

- Built with Three.js for 3D rendering
- Uses OrbitControls for camera interaction
- Responsive design with CSS media queries
- Pure JavaScript implementation (no frameworks)
